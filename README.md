# hxwl-05 多缸水质值班台

水族店晚班交接用的多缸水质值班台：读数登记、超限开单、换水排期与交班责任转移。

## 技术栈

React + Vite + TypeScript + CSS（数据保存在浏览器 localStorage，无需后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能说明

- **鱼缸与品种上限**：草缸、海缸、三湖缸、繁殖缸、大型鱼缸各有水温 / pH / 氨氮 / 硝酸盐上限。
- **读数登记**：录入四项读数，提交时实时比对品种上限；超限字段当场标红。
- **超限待处理项**：超过品种上限自动生成待处理项（含开单时间、责任班次、超限幅度与紧急度），并自动生成换水任务。
- **同缸同项只补检查记录**：同一缸同一指标在待处理项未关闭前再次测超限，不重复开单、不重复排队，只追加一条复测检查记录。
- **换水排期**：换水任务按紧急度（氨氮 / 硝酸盐权重更高）从当晚 20:00–23:30 的 7 个时段中依次占位；一个鱼缸一晚只占一个时段；冲突项停在「待排」并写明原因（本缸已占时段 / 时段已满），完成换水后自动顺延补位。
- **筛选视图**：待处理、换水、已完成、全部四个页签，顶部统计卡可快速跳转。
- **交班**：早班 → 晚班 → 夜班循环，交班后所有未关闭待处理项和进行中换水任务的责任人转到下一班，交接链留痕。
- **持久化**：全部状态存于 localStorage（键 `hxwl-05-duty-desk:v1`），关闭再打开自动接续；「重置演示」可恢复内置演示数据。

## 代码结构

- `src/types.ts`：领域类型
- `src/domain.ts`：品种上限、紧急度、读数入账、换水排程、交班等纯逻辑
- `src/seed.ts`：晚班演示数据（含补检记录、时段冲突、已完成历史单）
- `src/storage.ts`：localStorage 读写
- `src/App.tsx`：值班台界面与交互
